# 数据目录与运行步骤

官方TRAIN：148695张图像，750个类别文件夹0000—0749，放在本目录official/train/。相对路径和给定标签以train_index.json为准。官方TEST：37444张原始图像放在official/test/，文件名和顺序以test_names.json为准。仅提供空目录，原图由复现人员取得并按原样放置。不要改名、重编码、改动类别映射或补入额外图像。

所有运行命令在上一层“代码与数据”目录执行：

```bash
python validate_reproduction.py
python validate_reproduction.py --split train
python validate_reproduction.py --split test
CUDA_VISIBLE_DEVICES=0 bash run.sh ./pred_results.csv
python validate_reproduction.py --prediction ./pred_results.csv
```

完整训练入口为CUDA_VISIBLE_DEVICES=0 bash train.sh；各阶段、配置、统计生成和产物路径详见../README.md。仅需正式预测时，放置TEST并运行run.sh即可，不需要运行训练。官方初始化用于重新训练，最终预测直接使用上一层交付模型。像素缓存和模型特征缓存由代码生成，不能以部分TEST结果拼接替代完整查询图。

TRAIN标签含噪且没有独立标注验证集，训练诊断不应表述为独立验证成绩。统计生成不读取TEST标签。原图缺失、解码失败、模型SHA或预测CSV校验失败时停止，按报错定位原文件；不要自行修改校验值。结果CSV不含表头，应有37444行和两列：filename、category_id，类别编号必须保留四位字符串格式。
